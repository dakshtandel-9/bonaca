# src/assets

Reserved for assets that are imported by components (for example an SVG logo
or a locally hosted font file) rather than served statically.

Anything referenced by URL — property photography, favicons, social share
images — belongs in `/public` instead:

- `public/images/property/exterior` — exterior and elevation photography
- `public/images/property/interior` — living, dining and common spaces
- `public/images/property/rooms` — bedrooms and bathrooms
- `public/images/property/outdoor` — garden, veranda and outdoor seating
- `public/images/property/gallery` — images used by the gallery section
- `public/images/branding/logo` — wordmark and logo files
- `public/images/branding/icons` — favicons and app icons
- `public/images/placeholders` — temporary stand-in images, if ever needed
- `public/social` — Open Graph / Twitter share images

This directory is intentionally empty for now.
