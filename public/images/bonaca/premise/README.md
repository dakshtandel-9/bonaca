## Size

| | |
|---|---|
| **Aspect ratio** | **21:9** (cinematic ultra-wide) |
| **Recommended** | **2520 × 1080 px** |
| **Minimum** | 2000 × 857 px |
| **Format** | JPEG (not PNG — photographs are 8–10× larger as PNG) |

The box is 1456 px wide at most, so 2520 px covers high-density screens with
room to spare.

## Composition

On phones the same file is centre-cropped to 3:2, which keeps roughly the
middle 64% of the width. **Keep the subject centred** so nothing important
sits in the outer thirds.

Shoot or generate it to sit between a paragraph about the house and the room
counts — an exterior in daylight, a courtyard detail, or a wide interior all
work. Avoid another dusk exterior; the hero already owns that moment.
